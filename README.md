# Rabari Vedant — Premium Portfolio

Modern freelancer portfolio built with **Next.js**, **TypeScript**, **Tailwind CSS**, **Framer Motion**, **GSAP-ready architecture**, **React Three Fiber**, **Drei**, and **Lenis**.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Customize

- Personal info: `src/data/site.ts` (update LinkedIn, GitHub, Calendly URLs)
- Projects: `src/data/projects.ts`
- Skills / services: `src/data/*`

## Deploy to GitHub Pages

This is a **Next.js** app (not CRA), so it deploys a static export to the `out/` folder:

```bash
npm run deploy
```

Live site: https://vedant-dev007.github.io/Portfolio/

In GitHub → **Settings → Pages**, source should be the `gh-pages` branch and `/ (root)`.
